# SMANS - School Management System

A modern, full-stack school management application built with **Next.js 14/15**, **Prisma**, **NextAuth v5**, **Tailwind CSS + daisyUI**, and **Shadcn/UI**.

SMANS helps schools manage students, teachers, classes, attendance, exams, grades, fees, invoices, payments, notifications, and more — with role-based dashboards for admins, teachers, parents, and students.

## Features

- **Role-based access** (Admin, Teacher, Parent, Student)
- **Dashboard** with real-time stats and role-specific views
- **Students & Parents** management (CRUD + linking)
- **Teachers & Classes** (assign teachers, manage timetable)
- **Attendance** tracking (daily marking + reports)
- **Exams & Grades** (create exams, record results)
- **Fees & Finance** (fee items, invoices, payments, status tracking)
- **Notifications** (in-app + future SMS/email)
- **Audit logging** for actions
- Secure authentication with **NextAuth v5** (credentials)
- Fully type-safe with **TypeScript** + **Zod** validation
- Responsive UI with **Tailwind + daisyUI + Shadcn**

## Tech Stack

- **Frontend/Backend**: Next.js 14/15 (App Router)
- **Database**: PostgreSQL + Prisma ORM
- **Authentication**: NextAuth v5 (credentials)
- **Styling**: Tailwind CSS + daisyUI + Shadcn/UI
- **Forms**: React Hook Form + Zod
- **Icons**: Lucide React
- **Deployment-ready**: Docker support (future)
